# 💊 ผู้ช่วยยาสามัญประจำบ้าน (Household Medicine RAG Chatbot)

แชตบอตตอบคำถามเรื่อง **ยาสามัญประจำบ้านของไทย** ด้วยเทคนิค RAG (Retrieval-Augmented Generation)
ระบบค้นหาข้อมูลจากคลังเอกสารก่อน แล้วให้ LLM ตอบจากเอกสารที่ค้นได้เท่านั้น พร้อมแสดงแหล่งอ้างอิงทุกครั้ง

- **Web App:** https://labfinalnlp-czysquxhqbgcpbsgvfewbr.streamlit.app/
- **Source Code:** https://github.com/Alif024/LabFinal_NLP
- **ข้อจำกัด:** ใช้เพื่อการศึกษา ไม่ใช่คำแนะนำทางการแพทย์

## แนวคิดของ Domain

ยาสามัญประจำบ้านเป็นยาที่คนทั่วไปซื้อใช้เองได้โดยไม่ต้องมีใบสั่งแพทย์ แต่คนส่วนใหญ่ไม่รู้ว่ายาตัวไหนอยู่ในกลุ่มนี้
ใช้รักษาอาการอะไร หรือมีข้อควรระวังอะไร คำถามแบบนี้ต้องการคำตอบที่ **ถูกต้องและตรวจสอบที่มาได้**
ซึ่ง RAG เหมาะกว่าการให้ LLM ตอบจากความจำ เพราะ:

1. รายการยาอ้างอิง **ประกาศกระทรวงสาธารณสุข พ.ศ. 2568** ซึ่งใหม่กว่าข้อมูลที่ LLM ส่วนใหญ่เคยเรียนรู้
2. ทุกคำตอบอ้างอิงเอกสารต้นทาง ผู้ใช้กดลิงก์ไปตรวจสอบได้
3. ถ้าเอกสารไม่มีข้อมูล ระบบตอบว่า "ไม่พบข้อมูลในเอกสาร" แทนการเดา (สำคัญมากสำหรับเรื่องยา)

## แหล่งที่มาของเอกสาร

เอกสารทั้งหมดใน `data/` ดึงจาก **Wikipedia ภาษาไทย** (สัญญาอนุญาต [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/))
ผ่าน MediaWiki API เป็นข้อความล้วน ไม่ต้องทำ OCR จาก PDF ทุกไฟล์มีบรรทัด `แหล่งที่มา:` เก็บ URL พร้อม revision id ไว้
จึงเปิดดูต้นฉบับฉบับที่ใช้จริงได้เสมอ

| ไฟล์ | เนื้อหา | แหล่งที่มา |
|---|---|---|
| `00_ภาพรวม...` | นิยามและรายชื่อ 16 กลุ่มยา | [ยาสามัญประจำบ้าน](https://th.wikipedia.org/wiki/ยาสามัญประจำบ้าน) |
| `01`–`16` | รายการยาแต่ละกลุ่ม: ชื่อตำรับ ตัวยาสำคัญ สรรพคุณ ขนาดบรรจุ | [ยาสามัญประจำบ้าน](https://th.wikipedia.org/wiki/ยาสามัญประจำบ้าน) (อิง[ประกาศกระทรวงสาธารณสุข พ.ศ. 2568](https://ratchakitcha.soc.go.th/documents/81120.pdf)) |
| `20_พาราเซตามอล` | ขนาดยา ความเป็นพิษต่อตับ | [พาราเซตามอล](https://th.wikipedia.org/wiki/พาราเซตามอล) |
| `21_แอสไพริน` | ฤทธิ์ข้างเคียง กลุ่มอาการไรย์ | [แอสไพริน](https://th.wikipedia.org/wiki/แอสไพริน) |
| `22_คลอเฟนะมีน` | ยาแก้แพ้ อาการข้างเคียง | [คลอเฟนะมีน](https://th.wikipedia.org/wiki/คลอเฟนะมีน) |
| `23_มะขามแขก` | สมุนไพรยาระบาย | [มะขามแขก](https://th.wikipedia.org/wiki/มะขามแขก) |
| `24_ยาหม่อง` | ประวัติและสรรพคุณ | [ยาหม่อง](https://th.wikipedia.org/wiki/ยาหม่อง) |
| `25_ยาดม` | ยาดม | [ยาดม](https://th.wikipedia.org/wiki/ยาดม) |

รวม **23 ไฟล์ ประมาณ 50,000 ตัวอักษร** สร้างใหม่ได้ด้วยคำสั่ง `python scripts/build_data.py`
(สคริปต์แปลงตาราง wikitext เป็นข้อความแบบ "ชื่อฟิลด์: ค่า" เพื่อให้แต่ละตำรับยาอ่านเข้าใจได้ในตัวเอง)

## สถาปัตยกรรมระบบ RAG

```
คำถาม ─► (1) Query condensation ─► (2) Embedding ─► (3) FAISS top-k ─► (4) Prompt + Context ─► Groq LLM ─► คำตอบ + แหล่งอ้างอิง
          เขียนคำถามต่อเนื่อง        multilingual-e5     cosine similarity    ตอบจาก context เท่านั้น
          ให้สมบูรณ์ในตัว            -small              (IndexFlatIP)        อ้าง [n] / "ไม่พบข้อมูล"
```

| ขั้นตอน | รายละเอียด (ใน `app.py`) |
|---|---|
| **Document Loading & Cleaning** | อ่าน `data/*.txt` แยกส่วนหัว (ชื่อ/แหล่งที่มา) ออกจากเนื้อหา แล้วทำความสะอาดด้วย `pythainlp.util.normalize` (แก้สระ/วรรณยุกต์ซ้ำ) ลบ zero-width space และช่องว่างเกิน |
| **Chunking** | แบ่งตามโครงสร้างก่อน: ยา 1 ตำรับ (`## ...`) ไม่ถูกตัดแยกกัน ย่อหน้าสั้นถูกรวมให้ได้ราว 700 ตัวอักษร ย่อหน้ายาวถูกตัดที่ช่องว่าง (ซึ่งภาษาไทยใช้คั่นประโยค) ซ้อนกัน 120 ตัวอักษร และใส่ชื่อเอกสารไว้หน้าทุก chunk เพื่อให้ embedding รู้บริบท ได้ทั้งหมด 87 chunks |
| **Embedding** | [`intfloat/multilingual-e5-small`](https://huggingface.co/intfloat/multilingual-e5-small) (118M พารามิเตอร์ รองรับภาษาไทย ขนาดเล็กพอสำหรับ Streamlit Cloud) ใส่ prefix `passage:` / `query:` ตามที่โมเดลกำหนด และ normalize เวกเตอร์ |
| **Vector Search** | FAISS `IndexFlatIP` (inner product ของเวกเตอร์ normalize = cosine similarity) โมเดลและ index โหลดครั้งเดียวด้วย `@st.cache_resource` |
| **Prompt Engineering** | System prompt บังคับให้ตอบจาก `<context>` เท่านั้น อ้างอิง `[n]` ทุกข้อเท็จจริง ตอบ "ไม่พบข้อมูลในเอกสาร" เมื่อไม่มีคำตอบ และแนะนำให้ปรึกษาเภสัชกรเมื่อถามเรื่องขนาดยา context ใส่ในแท็ก `<doc id title>` ใช้ temperature 0.1 |
| **LLM** | Groq API (`openai/gpt-oss-120b` ค่าเริ่มต้น เปลี่ยนได้ผ่าน secret `GROQ_MODEL`) แสดงคำตอบแบบ streaming |
| **Conversation** | เก็บประวัติแชตใน `st.session_state` ส่งประวัติล่าสุดให้ LLM และใช้ query condensation เปลี่ยนคำถามต่อเนื่อง เช่น "แล้วเด็กกินได้ไหม" เป็นคำถามที่สมบูรณ์ก่อนค้นหา |
| **Interface** | หน้าแชต (`st.chat_message`) แสดงเอกสารอ้างอิงใต้ทุกคำตอบ (ชื่อ ลิงก์ ไฟล์ คะแนนความใกล้เคียง ข้อความที่ค้นเจอ) ยกเว้นคำตอบ "ไม่พบข้อมูลในเอกสาร" ที่ไม่ได้อ้างอิงเอกสารใด ปุ่มคำถามตัวอย่าง ปรับ top-k ได้ ปุ่มล้างแชต และรายชื่อเอกสารทั้งหมด |

### ผลทดสอบ Retrieval

จาก `test_questions.csv` (15 ข้อ: มีคำตอบ 12 ข้อ ไม่มีคำตอบในเอกสาร 3 ข้อ) เอกสารที่ถูกต้องอยู่ใน top-5 ครบ **12/12 ข้อ (recall@5 = 100%)**
ส่วนคำถามที่ไม่มีคำตอบ (ราคายา วัคซีน ร้านขายยา) ระบบยังค้นเอกสารที่ใกล้เคียงที่สุดมาให้ แล้วให้ LLM เป็นผู้ตัดสินตาม prompt ว่าต้องตอบ "ไม่พบข้อมูล"

ทดสอบทั้งระบบกับ LLM จริง (`openai/gpt-oss-120b`): ตอบถูกพร้อมอ้างอิงครบ 12 ข้อ และตอบ "ไม่พบข้อมูลในเอกสาร" ถูกต้องทั้ง 3 ข้อที่ไม่มีคำตอบ
ระหว่างทดสอบพบและแก้ 2 จุด: (1) ข้อ 12 ที่เอกสารระบุว่ากลุ่มยา "ไม่มี" รายการ LLM ตอบว่าไม่พบข้อมูล จึงเพิ่มข้อยกเว้นพร้อมตัวอย่างใน prompt
(2) LLM บางครั้งอ้างอิงด้วย `【1】` จึงแปลงเป็น `[1]` ให้เหมือนกันทุกคำตอบ

## วิธีใช้งาน

### ใช้งานบนเว็บ
1. เปิด https://labfinalnlp-czysquxhqbgcpbsgvfewbr.streamlit.app/
2. พิมพ์คำถามในช่องแชต หรือกดคำถามตัวอย่างที่แถบด้านซ้าย
3. อ่านคำตอบ ตัวเลข `[n]` คือหมายเลขเอกสารอ้างอิง กด **📚 เอกสารอ้างอิง** เพื่อดูข้อความต้นทางและลิงก์
4. ถามต่อเนื่องได้ เช่น "พาราเซตามอลกินได้วันละเท่าไร" แล้วตามด้วย "ถ้าดื่มเหล้าล่ะ"

### รันบนเครื่องตัวเอง
```bash
pip install -r requirements.txt
cp .streamlit/secrets.toml.example .streamlit/secrets.toml   # แล้วใส่ GROQ_API_KEY
streamlit run app.py
```

### Deploy บน Streamlit Community Cloud
1. Push repo ขึ้น GitHub (ตรวจว่า **ไม่มี** `.streamlit/secrets.toml` ใน repo)
2. ที่ [share.streamlit.io](https://share.streamlit.io) เลือก repo และไฟล์หลัก `app.py`
3. **Advanced settings** เลือก Python 3.12 และใส่ใน **Secrets**:
   ```toml
   GROQ_API_KEY = "gsk_..."
   GROQ_MODEL = "openai/gpt-oss-120b"
   ```
4. Deploy แล้วลองเปิดในโหมด Incognito

## ตัวอย่าง Prompt ที่ใช้สั่ง AI

โปรเจกต์นี้พัฒนาร่วมกับ AI ผู้ช่วยเขียนโปรแกรม (Claude Code) ตัวอย่าง prompt ที่ใช้:

1. `NLP-SubTest2.ipynb จากไฟล์นี้สรุปสิ่งที่ต้องทำ`
2. `แนะนำหัวข้อที่ไม่ได้อยู่ในตัวอย่างมาให้หน่อย`
3. `อยากได้พร้อมข้อมูลอ้างอิงด้วยว่าแหล่งข้อมูลมาจากไหน ขอหัวข้อที่มีแหล่งข้อมูลที่เป็นข้อความหากเป็นไปได้ ถ้าเป็นไฟล์ pdf จะมีความเสี่ยงด้าน ocr`
4. `อยากได้หัวข้อ ผู้ช่วยยาสามัญประจำบ้าน` (AI ช่วยเขียนสคริปต์ดึงข้อมูล, app.py, คำถามทดสอบ และทดสอบ retrieval)

Prompt ที่ระบบใช้สั่ง LLM ขณะตอบคำถาม (system prompt) อยู่ในตัวแปร `SYSTEM_PROMPT` และ `CONDENSE_PROMPT` ใน `app.py`
